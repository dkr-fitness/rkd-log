# RKD Mesocycle 03

**Dates:** Mon 10/19 – Sun 12/13 (8 weeks)
**Follows:** Mesocycle 02 (9/7–10/18), which ran Baseline ×2 then Volume ×4 for muscle gain.
**Basis:** Same Mon/Wed/Fri split structure as Meso 02, plus a scored Saturday. Back Squat, Goblet Squat and Floor Push-Ups are not in this block. Safety Bar Squat takes the squat slot.

## Design Logic

**Phases.** Eight weeks: Baseline ×2, Volume ×3, Performance ×2, then one Deload week. It's the first block with a Performance phase actually in use (Meso 02's plan dropped it) and the first with a Deload.

**Main lifts vs accessories.** One lift per training day follows the main-lift progression: Rack Pull (Mon), Safety Bar Squat (Wed), Romanian Deadlift (Fri). Everything else follows the accessory progression, except the activation slots and the carry/grip work, which stay fixed.

**Unilateral work.** Single-arm and per-side work runs right side first. The movement names stay as they were, with the single-arm or per-side detail in the prescription, so PR history carries over. The exception is Chest Press, which logs under the existing `SA Chest Press` key so per-arm loads aren't compared against two-arm history.

**Saturday.** Meso 01 and 02 had no scored Saturday; the shared Conditioning Sub was cardio-ramp reference only. In Meso 03, Saturday is a full-range session scored like a lifting day: strength curve, a plan-completion medal (see Lift-day medal, below), and it counts in weekly totals. Effort is still capped at 7/10.

## Progression

| Weeks | Phase | Main lifts | Accessories |
|---|---|---|---|
| 1–2 | Baseline | 4×6 @ RPE 6–7 | 3×8–10 |
| 3–5 | Volume | 5×6–8 @ RPE 7–8 | 3×10–12 |
| 6–7 | Performance | 4×4–5 @ RPE 8 | 3×8, heavier |
| 8 | Deload | 3×5 @ RPE 6 | 2×8 |

**Main lifts:** 1–2 ramp sets, not logged, then all working sets at one weight. Ramp sets are never set rows in the app, so they don't count toward the plan score.

**Weight hints (app, every Meso 03 exercise):** set 1's grey hint is last time's top working weight. Once set 1 has a weight, sets 2+ hint that same weight instead of last time's pyramid. They're hints only: a typed value is never overwritten, and tapping Same as last (or ±5) in set mode turns the hint into a value. Set 1's reps hint comes from that same top set, so Same as last fills a pair you actually lifted. Sets 2+ keep last time's reps, set for set.

**Loading progression** (shown in the app's Scoring box on every Meso 03 lift day): Main lifts: all sets at RPE 7 or easier → add 5 lb next week (Rack Pull 10 lb). Accessories: stay at one weight until every set hits the top of the rep range, then go up. Single-arm: right side sets the load; left matches.

**Week 3 loads (Nov 2–8, set 2026-10-31):** each loaded card shows "Week 3: <load>" in its rx, and the progression line "Hit all sets at top of range → add load next week; if not, hold." For that week the Scoring box's Loading line shows the same rule in place of the RPE rule above (the single-arm sentence stays). Set 1's grey weight hint is the target, not last time's top set, so Same as last and ±5 build on it. Set 1's reps hint is still last time's top-set reps. Wed Safety Bar Squat and Sat Leg Press add: "Hold last week's load if recovery is red or sleep <5.5 h." From week 4, Last time leads again.

Pallof's set 1 hint is 7.5 lb, the bottom of its range. Sled Push has no weight hint: 0.8 mph is a speed, not a load. Activation slots without a load (Band Pull-Aparts, Scapular Wall Slide) and Friday's Core get no target or line.

**Starting weights (Baseline, weeks 1–2 only):** each session table below has a Start column, and the app shows it in the rx as "Start ~X". From week 3 it's dropped: week 3 has its own targets (above), and from week 4 set mode's Last time line takes over. Calibrate on the first working set: RPE 8+ → drop 10%. RPE 5 → add 5–10 lb. That line is in the Baseline phase cue (the app's HR target box, Mon/Wed/Fri). Saturday's is fitted to its 7/10 cap instead: first working set above 7/10 → drop 10%.

**Fixed all block:** activation slots (2 sets). Suitcase Carry runs 2 rounds, dropping to 1 in the Deload week.

**Single-arm lifts** (Chest Press, Rope Triceps Pressdown, Neutral-Grip Row): optional extra set, right arm only. Log it with + Set; it doesn't change the prescribed sets or the plan score.

**Week 8 retest (Mon/Wed/Fri):** repeat Baseline loads for carries and single-arm lifts; log both sides. The pinch hold retests in the HEP, where it's now logged. The app shows this as a banner on those days and tags each affected exercise with "retest". Results go in the plan's Right-Side Tracker tab.

## Session Templates

Rx below is the Baseline prescription. Main lifts and accessories follow the progression table. Start is the Baseline-only starting weight.

**Session flow (changed 2026-10-26, for shorter sessions).** Sessions had been running 61–81 min. Main lifts stay standalone blocks on their own bells. Accessories run in rounds:
- **Per-side:** one round = right side, then left straight away, then rest ("right → left → rest").
- **Superset:** A1 → A2 → rest. Set mode already walks it A1, A2, A1, …
- **Rest:** ~60–90 s after each full round. Each accessory block's bell interval is the round's work plus ~75 s.

Set counts didn't change, so neither did the plan score.

**Estimated time** is shown on each lift day. It's 15 min for the HEP Gym block + activation (the session clock starts when WHOOP links on arrival, so logged durations include the HEP), plus each block's bells × interval, plus 3 min of ramp sets per main lift, plus ~1 min per change of station. The app turns it amber over 65 min.

## Conditioning

**Tue/Thu Zone 2:** shared with every block. Strength curve, medal on % of session time in Z2. **Thursday in this block:** check WHOOP recovery first: green → Zone 2, 25–35 min · yellow/red → easy walk or mobility 20–30 min instead. The app shows that in Thursday's rule box inside the Meso 03 window only.

**Saturday:** see above. This block's Saturday is its own template (`meso03Sat`). The shared Sat Conditioning Sub stays as-is for history and outside this window, and it's still unscored.

**Sunday:** CS4, active recovery. Never scored.

**Lift-day medal (Mon/Wed/Fri/Sat):** plan completion, not heart rate. RKD still accrues on the strength curve and counts in weekly totals, but the medal is sets done ÷ sets prescribed across every exercise, activation and the right-side slots included. A pain entry not marked "went away" counts that exercise as complete. A progression is a top set that beats Last time on load, or on reps at the same load, with no pain logged on it. Gold = 100% + a progression · Silver = 100% · Bronze = 80%+ · below that, Partial. Saturday (cap 7/10) and the week 8 Deload take Gold at 100% with no progression needed.
